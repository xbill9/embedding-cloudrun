More EmbeddingGemma 2 on Cloud Run.

How small can the service go, and when does a Cloud Run NVIDIA L4 pay for itself?

A 1 vCPU, 2 GiB Cloud Run service with int8 weights is usually enough.
Queries take a median 133 ms and a million documents cost USD 27.67.

Both the CPU service and the L4 scale to zero, and both have cold starts.

The L4 is about 16x cheaper per document while busy, so it wins once a burst passes about 5,300 documents. Below that, the CPU service is cheaper. An L4 kept warm costs USD 764 a month.

An int4 repack is 28% smaller, but slower on CPU and needs 3 GiB, because the server runs it in float32.
